## 我想快速判断一个安全问题该怎么处理

- 入口：[[./08-Playbooks/安全快速诊断 Playbook|安全快速诊断 Playbook]]
- 地图：[[./06-Maps/安全问题解决工作台|安全问题解决工作台]]
- 典型问题：
  - 这个问题是不是 P0/P1？
  - 影响的是账号、数据、应用、云还是供应链？
  - 先止血、先修复、先取证还是先通报？
  - 有没有 owner、截止时间和补偿控制？

## 我不知道应该先保护什么

- 入口：[[./05-Topics/企业安全架构|企业安全架构]]
- 追问：
  - 核心资产是什么？
  - 哪些系统暴露在公网？
  - 哪些身份有高权限？
  - 哪些数据受地区或行业监管？

## 我担心账号、权限、密钥被滥用

- 入口：[[./05-Topics/身份与访问安全|身份与访问安全]]
- 关联：[[./05-Topics/零信任架构|零信任架构]]
- 典型问题：
  - 是否启用 MFA
  - 是否有过期权限
  - API key / secret 是否可轮换
  - 高权限操作是否有审批和审计

## 我担心公网入口、DDoS、扫描和横向移动

- 入口：[[./05-Topics/网络安全|网络安全]]
- 关联：[[./06-Maps/攻击面与控制点图|攻击面与控制点图]]
- 典型问题：
  - 哪些服务暴露公网
  - 网络是否分段
  - 边界是否有 WAF / DDoS 保护
  - 内网横向移动如何被发现

## 我担心客户端、移动端、浏览器和终端被打

- 入口：[[./05-Topics/客户端安全|客户端安全]]
- 典型问题：
  - 终端是否可信
  - App 是否可被逆向和篡改
  - 本地是否缓存敏感数据
  - 钓鱼和恶意插件如何防

## 我担心应用和 API 被越权、注入或业务滥用

- 入口：[[./05-Topics/应用安全与 API 安全|应用安全与 API 安全]]
- Playbook：[[./08-Playbooks/应用与 API 安全评审 Playbook|应用与 API 安全评审 Playbook]]
- 关联：[[./05-Topics/安全工程与 DevSecOps|安全工程与 DevSecOps]]
- 典型问题：
  - 是否有 broken access control
  - API 是否做了 rate limit 和 abuse detection
  - 业务逻辑是否可被绕过
  - 安全测试是否进入 CI/CD

## 我担心敏感数据、个人信息和隐私合规

- 入口：[[./05-Topics/数据安全与隐私保护|数据安全与隐私保护]]
- Playbook：[[./08-Playbooks/数据安全与隐私评审 Playbook|数据安全与隐私评审 Playbook]]
- 关联：[[./05-Topics/地区合规与监管坐标|地区合规与监管坐标]]
- 典型问题：
  - 数据是否分类分级
  - 是否最小化收集
  - 是否加密、脱敏、审计
  - 是否涉及跨境传输和数据驻留

## 我担心云账号、容器、Kubernetes 和配置暴露

- 入口：[[./05-Topics/云原生与基础设施安全|云原生与基础设施安全]]
- 关联：[[../Cloud-Native/03-Topics/云原生安全|云原生安全]]
- 典型问题：
  - 云 IAM 是否过权
  - 存储桶是否公开
  - 镜像是否有漏洞
  - Kubernetes RBAC / NetworkPolicy 是否合理

## 我担心依赖、镜像、构建和第三方 SDK 被投毒

- 入口：[[./05-Topics/供应链安全|供应链安全]]
- 关联：[[./05-Topics/安全工程与 DevSecOps|安全工程与 DevSecOps]]
- 典型问题：
  - 是否有 SBOM
  - artifact 是否签名
  - CI/CD secret 是否泄露
  - 第三方供应商是否评估

## 我想知道攻击来了怎么发现和响应

- 入口：[[./05-Topics/安全运营、检测与响应|安全运营、检测与响应]]
- 地图：[[./06-Maps/安全运营与事件响应闭环图|安全运营与事件响应闭环图]]
- Playbook：[[./08-Playbooks/安全事件响应 Playbook|安全事件响应 Playbook]]
- 典型问题：
  - 哪些日志进入 SIEM
  - 告警如何分级
  - incident commander 是谁
  - MTTD / MTTR 如何衡量

## 我想知道怎么做安全治理和审计

- 入口：[[./05-Topics/安全治理、风险与合规|安全治理、风险与合规]]

  - 控制如何证明有效

## 我想处理地区合规
